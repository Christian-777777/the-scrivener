## 这个工具是什么

你写小说时，可能有几十个人物、每个国家有自己的历史、地图上散落着上百个地标、物品之间有合成关系、怪物分布在不同区域。用 Word 或 Notion 管理这些信息，很快就会迷失在文档海洋里——谁和谁有什么关系？这座城市在哪个国家？这个物品由什么材料合成？

**世界OC编辑器**把所有这些信息放在同一本书里。你翻开的每一页，是编年史、是地图、是人物档案、是物品图鉴。你写下的任何地名、人名、物品名，会自动变成可点击的链接，点一下就跳到对应的详情页。不需要手动维护交叉引用，编辑器替你做了。

---

## 使用场景

**小说作者** — 写长篇幻想小说时，用它管理几十个角色的档案、朝代更迭的时间线、大陆各国的地理关系。写正文时不用来回翻人物设定表。

**TRPG 主持人** — 跑团前把世界设定整理好，开团时地图、地标、人物随时查阅。关系图谱帮你记住每个 NPC 和谁认识、和谁有仇。

**游戏策划** — 搭建世界观原型。编年史梳理剧情节点，物品合成图谱设计配方树，地图规划关卡分布。

## 功能导览

### 世界编年史

纵向时间轴，模拟史书排版。添加时间节点记录重大事件——「王国历 328 年，龙脊山脉之战」。每个节点可以拖拽出分支：同一场战役，北方王国和南方帝国各自的视角可以分开记述。

用「划分时代」把时间轴切成纪元——第一纪元、龙火时代、灰烬重建期。划分后，该时代内的所有节点和连接线自动变成统一的主题色。视觉上，你的历史不再是一堆散点，而是一段一段有颜色的时空。

### 世界地图

一张 1200×800 的画布。右键点击任意位置，创建一个地标——王都、城邦、村庄、部落、港口、森林、废墟、火山……共 16 种类型。每个地标可以自定义颜色、尺寸，选择一个图标。

用自由画笔在地图上划定区域——画出王国的疆界、画出那片禁忌之林的轮廓，区域内部有半透明色覆盖，边缘清晰。地标如果归属于某个区域，会自动同步该区域的颜色。

**同一地名在多个地图上同时出现。** 如果你有「主大陆」和「北部放大图」两张地图，在任意一张上创建的「霜语城」会同步到另一张。不需要手动复制。

### 人物库

两栏布局：左侧是人物卡片网格，右侧是详情面板。

每个角色可以填写：姓名、身份、种族、出生地、年龄、实力、称号。16 枚中世纪风格的预设头像图标可选，也可以导入自己的图片。

自定义分类标签——「主角」「反派」「贵族」「已故」——拖动排序决定主标签。主标签的颜色就是这个人物的主题色，自动显示在卡片边框和关系图谱节点上。

**人物关系图谱**：把左侧的人物卡片拖入右侧画布，在节点之间拉线。直线或直角连线，单向或双向箭头。右键连线填入关系文本：「誓约之剑的主人」「血仇」。鼠标悬停在线段上才会显示，保持画面干净。

一个世界可以有多个图谱——「政治势力关系图」「家族血缘图」「教团网络图」——各自独立。

### 物品库

和人物库同一套交互模式，但更侧重属性管理。除了名称和分类标签，每个物品可以添加任意自定义属性：攻击力、耐久度、附魔效果、材料来源……都是 key-value 对。

**合成图谱**：和人物图谱相同画布逻辑，但节点变成圆角矩形。拖入物品，连线。设计一把「龙鳞长剑」需要的材料链条：龙鳞 → 龙鳞长剑，秘银锭 → 龙鳞长剑，龙鳞 + 秘银锭 → 龙鳞长剑。配方树一目了然。

### 怪物手册

和物品库结构一致。有原生属性栏：种族、等级、栖息地，外加自定义属性编辑器。每个怪物也可以打分类标签——「龙类」「不死族」「野外 BOSS」——方便按类型筛选。

### 图书馆

左侧是书架网格，每本书显示封面预览。右侧是阅读和编辑面板。

把你的世界设定、短篇故事、跑团剧本写在这里。支持富文本编辑。作者栏下拉绑定人物库中的角色——书中的书，由你世界的居民所写。封面可以导入图片。

### 全局词条联动

这是编辑器最核心的功能。你创建一个人物「艾琳娜」，在编年史的事件描述里写下「艾琳娜率领骑士团突围」，地图上建了一座「艾琳娜的故居」，图书馆某本书里提到「艾琳娜曾在此停留」——所有这些地方的「艾琳娜」都会被识别为同一个词条。

点击任意「艾琳娜」文本，会跳转到搜索页，列出所有提到了她的地方：编年史中哪几处、地图上哪个地标、图书馆哪本书。像一个专属于你世界的搜索引擎。

### 背景音乐

右下角金色音符按钮，展开播放器。切换曲目、调节音量、静音。打开应用自动续播。把三首中世纪氛围音乐放进 `public/music/`，写作时沉浸在合适的环境音里。

## 截图

> 将应用截图放入 `screenshots/` 文件夹，推荐以下角度：
>
> - `cover.png` — 书本封面（关闭状态）
> - `chronicle.png` — 编年史时间轴（编辑模式 + 时代划分）
> - `map.png` — 地图编辑器（含地标节点和区域）
> - `character.png` — 人物集（左侧卡片网格 + 右侧详情面板）
> - `graph.png` — 人物关系图谱（圆形节点 + SVG 连线）
> - `library.png` — 图书馆（书架网格 + 阅读面板）
> - `player.png` — 背景音乐悬浮播放面板

## 下载

前往 [Releases](../../releases) 下载最新版压缩包，解压后双击 `世界OC编辑器.exe` 即可运行。无需安装 Node.js 或其他依赖。

---

## 从源码构建

**需要：** Node.js ≥ 18，npm ≥ 9

```bash
git clone https://github.com/Christian-777777/the-scrivener.git
cd the-scrivener
npm install
npm run release
```

产物在 `release/世界OC编辑器/`。
